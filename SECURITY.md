# Security policy

Report suspected Pannonico VS Code extension vulnerabilities through the
shared
[GitHub private vulnerability reporting form](https://github.com/vx-rs/pannonico/security/advisories/new).
Do not disclose vulnerability details in this repository's public Issues.

Include the extension, VS Code, WASM WASI Core, and pinned LSP versions; whether
the workspace is local or Remote-WSL; reproduction steps; impact; and any
suggested mitigation. Remove credentials, personal data, and confidential
project content.
