# Security policy

Report suspected Pannonico VS Code extension vulnerabilities through the
shared
[GitHub private vulnerability reporting form](https://github.com/vx-rs/pannonico/security/advisories/new).
Do not disclose vulnerability details in this repository's public Issues.

Include the extension, VS Code, pinned LSP version and WASM SHA-256, and
whether the workspace is local, Remote-WSL, Remote-SSH, or a Dev Container;
include reproduction steps, impact, and any suggested mitigation. Remove
credentials, personal data, and confidential project content.
